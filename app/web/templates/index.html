      Code format
      
      
      Full codes grow by level: 33 → 3301 → 330101 → 3301012001. short_code splits them as 33/01/01/2001.
      
    
      
    
      
      
      Parent chains
      
      
      Lookups return the full chain up to the province. Lists return only the direct parent, and only with ?parent=true.
      
    
      
    
      
      
      Kinds
      
      
      Regency segments 71–99 are cities (kota), the rest regencies (kabupaten). A village segment starting with 1 is an urban village (kelurahan), 2 a village (desa), 3 a customary village (desa adat).
